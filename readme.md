# What This Project Is  
This two table CRUD framework (React-Vite/Node-Express | postgres) was modified from my [CS3010 Full Stack Dev class](https://github.com/chickens5/CS3010-FullStack-)


# To launch

Use pgadmin4 and run the SQL file

Inspect package.json & vite.config.js

Open terminal and install the JSX dependencies in the /backend & /frontend:
`npm install`

Then, you need a .env file in both directories to connect to the servers
